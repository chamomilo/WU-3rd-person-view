# Local build dependencies

This directory intentionally does not distribute Wurm Unlimited client files
or other binary build dependencies. Place the following pinned JARs here
before building:

- `client-patched.jar`
- `common.jar`
- `javassist.jar`
- `modlauncher.jar`
- `junit-4.13.2.jar`
- `hamcrest-core-1.3.jar`

Use files from a legally installed Wurm Unlimited client and compatible client
mod-loader development environment. These dependencies are not covered by the
project's GPL-3.0 license.
